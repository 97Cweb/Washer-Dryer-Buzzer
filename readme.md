# Washer Dryer Buzzer
A thing to build to put buzzers back on the washing machine and dryer

V1 used a photoresistor on the washing machine
V2 uses 2 optocouplers to get the washing machine knob position.

Both use a non invasive current sensor for the dryer to get whether it is on or not.

You will also need a speaker module to get enough volume from the audio.

Modules used:
5PCS IR Infrared Slotted Optical Optocoupler Speed Measuring Sensor Module 3.3-5V for Arduino Also for Smart Robot Car Speed Measurement with Dupont Wire [Amazon](https://www.amazon.ca/dp/B09TK2H9NY)

Non-Invasive Current Sensor (30A) [Canada Robotix](https://www.canadarobotix.com/products/246?variant=14423519297585)


How to wire current sensor [link](https://www.engineersgarage.com/non-invasive-current-sensor-with-arduino/)
